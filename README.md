# river_flood_sim
River flood simulator — 1-D river channel, 2-D floodplain, sewer network and pumps, levee breach — with a Windows window app (Japanese and English screens) — design docs and code from the book Toward a Million Lines XIII / 河川氾濫シミュレータと窓のアプリ（Windows・日英の画面）— 本『LLM で 100 万行のソフトウェア開発 XIII』の設計書とコード
